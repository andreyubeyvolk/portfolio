ARCHIVE DATA — рабочий список карточек Archive
================================================

Как заполнять: один блок на картинку, блоки разделены пустой строкой.
Поля: Заголовок / Теги / Описание — каждое на своей строке.
Теги — через запятую, можно оставить пустым, если не нужны.

Порядок блоков в этом файле = порядок карточек на странице.
Хочешь вставить новую карточку между существующими — просто вставь
блок в нужное место файла, ничего пересчитывать/переименовывать не надо.

Пример:
archive-longread-01.webp
Заголовок: Text Longread Intensive
Теги: Web
Описание: Wow

archive-disruptive-series-02.webp
Заголовок: Disruptive Series
Теги: AI, Merch
Описание: Кадр 2 — деталь принта на спине.

Имя файла — по конвенции:
  archive-тема.webp              — одна отдельная картинка
  archive-тема-01.webp, -02...   — несколько ОТДЕЛЬНЫХ карточек на одну тему
                                    (каждая свой блок, свой заголовок)
  archive-тема-series-01.webp,   — НАСТОЯЩАЯ серия: одна карточка в сетке,
  -series-02...                    внутри — горизонтальный скролл по всем
                                    фото серии (см. обсуждение в чате)
